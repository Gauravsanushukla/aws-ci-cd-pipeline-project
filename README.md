#  AWS CI/CD Pipeline Project

## 📌 Overview
This project demonstrates a complete CI/CD pipeline using AWS services.

## 🛠️ Services Used
- AWS CodeCommit
- AWS CodeBuild
- AWS CodePipeline
- AWS CodeDeploy
- EC2

## ⚙️ Features
- Automated deployment on every code push
- Fully managed CI/CD pipeline
- Live application hosted on EC2

## 🧱 Architecture
CodeCommit → CodeBuild → CodePipeline → CodeDeploy → EC2
